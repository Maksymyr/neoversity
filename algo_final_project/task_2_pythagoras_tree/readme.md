# Завдання 2 — фрактал «дерево Піфагора»

Рекурсивна побудова бінарного фракталу «дерево Піфагора» через `matplotlib`. Рівень рекурсії задає користувач.

## Запуск

```bash
python pythagoras_tree.py 8           # рівень як аргумент
python pythagoras_tree.py             # запит у консолі
python pythagoras_tree.py 10 --angle 30 --ratio 0.75 --trunk 120
python test_pythagoras_tree.py        # тести
```

| Параметр    | Значення за замовчуванням | Опис                                |
|-------------|---------------------------|-------------------------------------|
| `level`     | (запитується)             | глибина рекурсії, рекомендовано 0..12 |
| `--angle`   | 45°                       | кут розходження гілок               |
| `--ratio`   | 0.7                       | відношення довжини дочірньої гілки до батьківської |
| `--trunk`   | 100                       | довжина стовбура                    |

## Реалізація

- `draw_branch(ax, x, y, length, angle, depth, ...)` — базовий випадок `depth == 0`; інакше малює відрізок і викликає себе двічі для лівої (`angle + delta`) і правої (`angle - delta`) гілок зі зменшеною довжиною.
- `draw_pythagoras_tree(level, ...)` — налаштовує matplotlib axes, починає рекурсію зі стовбура під кутом 90° (вертикально вгору).
- Soft-cap `level > 12` з підтвердженням `[y/N]`, оскільки `2^n` гілок при великих n.
- Тести мокають `ax.plot` і перевіряють математичні інваріанти: дерево глибини `n` має `2^n - 1` сегментів; сумарна довжина при `ratio=0.5` дорівнює `trunk * n` (геометрична прогресія).
