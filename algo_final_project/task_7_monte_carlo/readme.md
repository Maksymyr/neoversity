# Завдання 7 — метод Монте-Карло для двох кубиків

Імітація багатократного кидання двох гральних кубиків з обчисленням емпіричної ймовірності кожної можливої суми (2..12) і порівняння з аналітичним розподілом.

## Запуск

```bash
python monte_carlo_dice.py                              # 100k кидків, інтерактивне вікно
python monte_carlo_dice.py -n 1000000 --seed 42         # 1M кидків з фіксованим seed
python monte_carlo_dice.py -n 50000 --save plot.png     # зберегти у файл
python test_monte_carlo_dice.py                         # тести
```

## Теоретичний розподіл

Для двох кубиків можливих результатів `6 × 6 = 36`. Кожна сума має певну кількість сприятливих ісходів:

| сума | сприятливих | імовірність |
|------|-------------|-------------|
|  2   | 1 (1+1)     | 1/36 ≈ 2.78% |
|  3   | 2           | 2/36 ≈ 5.56% |
|  4   | 3           | 3/36 ≈ 8.33% |
|  5   | 4           | 4/36 ≈ 11.11% |
|  6   | 5           | 5/36 ≈ 13.89% |
|  7   | 6 (1+6, 2+5, 3+4, …) | 6/36 ≈ 16.67% |
|  8   | 5           | 5/36 ≈ 13.89% |
|  9   | 4           | 4/36 ≈ 11.11% |
| 10   | 3           | 3/36 ≈ 8.33% |
| 11   | 2           | 2/36 ≈ 5.56% |
| 12   | 1 (6+6)     | 1/36 ≈ 2.78% |

Розподіл **симетричний** відносно 7, найімовірніша сума — 7.

## Висновки

1. **Метод Монте-Карло коректно відтворює аналітичний розподіл.** При `N = 1 000 000` кидків абсолютна похибка для всіх 11 можливих сум не перевищує **0.05 процентного пункту**, а відносна похибка — **1.1%** (найбільша для краєвих сум 2 і 12, які мають найнижчу ймовірність).

2. **Точність зростає як √N.** За центральною граничною теоремою стандартна похибка частоти `p̂` дорівнює `σ = √(p(1−p)/N)`. Для `p = 1/36 ≈ 0.028` і `N = 10⁶` отримуємо `σ ≈ 0.017%` — а спостережувані похибки 0.005–0.043% укладаються у `~3σ` (типовий розкид випадкової вибірки).

3. **Симетрія розподілу зберігається.** Емпіричні частоти для пар `(2, 12)`, `(3, 11)`, `(4, 10)` тощо дуже близькі — як і має бути, бо ці пари мають однакову теоретичну ймовірність.

4. **Сума 7 — найімовірніша**, як і передбачає теорія: 16.63% емпірично vs 16.67% теоретично. Це фундаментальний факт із теорії ймовірностей, який тепер підтверджено емпірично.

5. **Висновок про метод.** Монте-Карло — потужний інструмент, коли аналітичний розв'язок неможливий або складний. Для двох кубиків аналітика тривіальна, але метод можна застосовувати до набагато складніших задач (інтегрування, фінансові моделі, статистична фізика, машинне навчання). Точність контролюється єдиним параметром — `N`, і вона **гарантовано** збігається до правильної відповіді при `N → ∞` (закон великих чисел).

6. **Обмеження.** При малих `N` (наприклад, 100 кидків) випадковий розкид перекриватиме теоретичні різниці між близькими сумами — це проявиться як «шумна» гістограма. Тому для серйозних висновків `N` має бути таким, щоб `σ` був суттєво меншим за різницю між сусідніми ймовірностями.
