# Завдання 1 — однозв'язний список

Реалізація трьох операцій над однозв'язним списком:

- **`reverse_list`** — реверсує список in-place, перепризначаючи `next`-посилання вузлів. Складність `O(n)`, додаткова пам'ять `O(1)`.
- **`sort_list`** — merge sort на зв'язному списку. На відміну від масиву, merge sort на linked list працює in-place (без додаткового масиву) і не потребує випадкового доступу. Складність `O(n log n)`.
- **`merge_two_sorted`** — об'єднує два **уже відсортовані** списки в один відсортований. Складність `O(n + m)`.

## Запуск

```bash
python linked_list.py        # демо: reverse, sort, merge
python test_linked_list.py   # тести
```

## Реалізація

- `merge_sort` використовує **slow/fast pointer** для розщеплення списку навпіл.
- `_merge_sorted_nodes` — спільна низькорівнева функція злиття двох списків, яку використовують і `sort_list`, і `merge_two_sorted`.
- Всі функції коректно обробляють порожній список і одиничний.
