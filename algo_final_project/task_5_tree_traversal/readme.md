# Завдання 5 — візуалізація DFS/BFS-обходу дерева

Обходи дерева в глибину (DFS) і в ширину (BFS) **без рекурсії** — через стек і чергу відповідно. Кожен вузол отримує унікальний колір з градієнта «темний → світлий» залежно від порядку відвідування.

## Запуск

```bash
python tree_traversal.py        # показує два вікна: DFS, потім BFS
python test_tree_traversal.py   # тести
```

## Реалізація

### Обходи (без рекурсії)

- **`dfs_iterative(root)`** — стек. Виштовхуємо вузол, додаємо його в `order`, потім кладемо в стек **спочатку правого**, потім лівого нащадка. Чому в такому порядку: стек LIFO, тож лівий буде виштовхнутий першим — це дає **pre-order** обхід (вузол → ліве піддерево → праве).
- **`bfs_iterative(root)`** — черга (`collections.deque`). Беремо з лівого кінця, додаємо нащадків у правий кінець. Це FIFO, тож виходить **рівневий обхід** (level-order).

### Градієнт кольорів

`gradient_color(step, total)` — для крок-індексу `0..total-1` повертає `#RRGGBB`:
- step = 0 → темний відтінок;
- step = total - 1 → світлий.

Реалізовано лінійною інтерполяцією яскравості: чим пізніше вузол відвідано, тим вища яскравість. Перевірка монотонності — у тестах.

### Приклад дерева

```
        0
       / \
      4   1
     / \ / \
    5 10 3 8
            /
           7
```

- **DFS**: `0 → 4 → 5 → 10 → 1 → 3 → 8 → 7`
- **BFS**: `0 → 4 → 1 → 5 → 10 → 3 → 8 → 7`

На малюнках кожен вузол підписано як `value\n#step` (порядковий номер відвідування), а колір йде від найтемнішого (#04253C — вузол відвіданий першим) до найсвітлішого (#70C0F6 — останній).
