# Завдання 4 — візуалізація бінарної купи

Функція, що візуалізує бінарну купу (heap) у вигляді дерева через `networkx + matplotlib`. За основу взято код із завдання — той самий клас `Node`, ті самі `add_edges` / `draw_tree`. Додано конвертацію heap-масиву в дерево вузлів.

## Запуск

```bash
python heap_viz.py   # демо: heapify + візуалізація
```

## Реалізація

**Ключова ідея.** Купа в Python (`heapq`) — це **масив** із неявною деревовидною структурою:
- Корінь — `heap[0]`.
- Діти вузла `heap[i]` — `heap[2i + 1]` і `heap[2i + 2]`.
- Батько вузла `heap[i]` — `heap[(i - 1) // 2]`.

**`heap_to_tree(heap)`** — будує дерево вузлів `Node`:
1. Створює `Node` для кожного елементу масиву (з тим самим індексом).
2. Для кожного `i` встановлює `nodes[i].left = nodes[2i+1]`, `nodes[i].right = nodes[2i+2]` (якщо індекси існують).
3. Повертає `nodes[0]` як корінь.

**`draw_heap(heap, title)`** — обгортка над наданою `draw_tree`-логікою: створює `nx.DiGraph`, обчислює позиції через `add_edges`, малює.

**Інваріант min-купи:** значення кожного вузла ≤ значень його дітей. На зображенні це видно — корінь завжди мінімум, і вниз по дереву числа не зменшуються (хоча в межах одного рівня — без порядку).
